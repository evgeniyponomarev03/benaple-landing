# HR Components Demo Page

This demo page showcases all the enhanced HR components with realistic dummy data to demonstrate their capabilities.

## 🎯 What's Included

### Components Demonstrated:

1. **HR Feature Showcase** - Grid layout with highlight features
2. **Statistics Display** - Multiple variants (minimal, default, modern)
3. **Testimonial Grid** - Customer reviews with ratings and avatars
4. **Call-to-Action** - Various styles and backgrounds
5. **Feature Grid** - Mixed layout with different card sizes
6. **Pricing Comparison** - Both card and table layouts

### Demo Data Features:

- **Realistic Content**: All dummy data reflects real HR use cases
- **Interactive Elements**: Animated counters, hover effects, transitions
- **Multiple Variants**: Shows different styling options for each component
- **Responsive Design**: Optimized for all screen sizes
- **Brand Integration**: Uses your brand colors throughout

## 🚀 Accessing the Demo
