# Insurance Page Setup Guide

## Quick Setup Instructions

1. **Access Payload Admin**: Navigate to `http://localhost:3000/admin` (once dev server is running)
2. **Create New Page**: Go to Collections → Pages → Create New
3. **Follow the sections below to configure each part**
